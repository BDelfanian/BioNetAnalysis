1 Introduction

This Quarto document demonstrates single-cell RNA-seq analysis using R packages SingleCellExperiment, Seurat, and scater. These tools are essential in bioinformatics for quality control (QC), normalization, dimensionality reduction, and clustering of single-cell transcriptomic data. We use the PBMC3k dataset to explore these methods.

2 Loading Libraries and Data

Load required libraries and the PBMC3k dataset from 10X Genomics. Ensure the data is unzipped and placed in the correct directory.

Code 
# Reset environment
rm(list=ls())

library(SingleCellExperiment)
library(dplyr)
library(Seurat)
library(patchwork)

# Download and unzip PBMC dataset from URL
url <- "https://s3-us-west-2.amazonaws.com/10x.files/samples/cell/pbmc3k/pbmc3k_filtered_gene_bc_matrices.tar.gz"
temp_file <- tempfile(fileext = ".tar.gz")
download.file(url, temp_file, mode = "wb")
temp_dir <- tempdir()
untar(temp_file, exdir = temp_dir)
pbmc.data <- Read10X(data.dir = file.path(temp_dir, "filtered_gene_bc_matrices/hg19"))

## Introduction

This Quarto document demonstrates single-cell RNA-seq analysis using R packages `SingleCellExperiment`, `Seurat`, and `scater`. These tools are essential in bioinformatics for quality control (QC), normalization, dimensionality reduction, and clustering of single-cell transcriptomic data. We use the PBMC3k dataset to explore these methods.

## Loading Libraries and Data

Load required libraries and the PBMC3k dataset from 10X Genomics. Ensure the data is unzipped and placed in the correct directory.

```{r}
# Reset environment
rm(list=ls())
```
