1 Introduction

This Quarto document demonstrates single-cell RNA-seq analysis using R packages SingleCellExperiment, Seurat, and scater. These tools are essential in bioinformatics for quality control (QC), normalization, dimensionality reduction, and clustering of single-cell transcriptomic data. We use the PBMC3k dataset to explore these methods.

## Introduction

This Quarto document demonstrates single-cell RNA-seq analysis using R packages `SingleCellExperiment`, `Seurat`, and `scater`. These tools are essential in bioinformatics for quality control (QC), normalization, dimensionality reduction, and clustering of single-cell transcriptomic data. We use the PBMC3k dataset to explore these methods.
